# MyTracker Requirements
## Functional Requirements
### Tasks
- The system shall allow users to create a task
- The system shall allow users to edit a task
- The system shall allow users to delete a task
- The system shall allow users to set a task as recurring
- The system shall allow users to set a recurring schedule for a task
- The system shall reset recurring tasks status based on the set schedule
- The system shall allow users to mark a task as completed
- The system shall allow users to view a list of tasks
- The system shall allow users to set a due date & time for a task
- The system shall allow users to set a priority level for a task
- The system shall allow users to receive notifications for tasks that are due to be completed
- The system shall allow users to set conditional termination for recurring tasks
- The system shall allow users to view a history of completed tasks

### Goals
- The system shall allow users to create goals
- The system shall allow users to edit goals
- The system shall allow users to delete goals
- The system shall allow users to add tasks to goals
- The system shall allow users to view a list of goals
- The system shall allow users to set a due date & time for a goal
- The system shall allow users to set a priority level for a goal
- The system shall allow users to view goal progress and completion status
- The system shall calculate and display completion percentage for goals based on the number of completed tasks associated with the goal

### Journal Entries
- The system shall allow users to create journal entries
- The system shall allow users to edit journal entries
- The system shall allow users to delete journal entries
- The system shall allow users to view a list of journal entries
- The system shall allow users to associate journal entries with one or more tasks or goals
- The system shall automatically timestamp journal entries with the date and time of creation
- The system shall allow users to search for journal entries based on keywords, associated tasks, or goals
- The system shall send a notification at the end of the day to remind users to create a journal entry for that day

## Non-Functional Requirements
- The system shall be accessible on multiple devices, including web and mobile platforms
- The system shall have a user-friendly interface that is easy to navigate
- The system shall ensure data security and privacy for user information
- The system shall provide real-time synchronization of data across devices
- The system shall have a responsive design that adapts to different screen sizes and orientations
- The system shall provide offline access to tasks, goals, and journal entries, with automatic synchronization when an internet connection is available
- The system shall prevent permanent data loss in case of accidental deletion or system failure
- The system shall function efficiently, with minimal latency and fast response times for user interactions
- The system shall be scalable to accommodate a growing number of users and data
- The system shall provide accessibility features to support users with disabilities, including screen reader compatibility and keyboard navigation
